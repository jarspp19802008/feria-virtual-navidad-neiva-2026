# Fotos comerciales públicas de la feria

Sube aquí las fotos preparadas desde Administración. Conserva el nombre generado y los originales en tu equipo. Las imágenes en esta carpeta son públicas: solo fotografías comerciales autorizadas, nunca documentos privados o credenciales.

Publicar un archivo no modifica la ficha. Espera el despliegue de GitHub Pages y pega su enlace en Administración para guardar las fotos del comercio.
